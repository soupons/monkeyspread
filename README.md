# monkeyspread

monkeytype but for spreading drills. pulls random evidence from an imported verbatim file based on selected criteria, tracks reading time and gives analytics.
if u think it'd be useful to add anything send me a dm on discord

## run it

it's a static site so you can run it yourself if you so please.

## add documents

Put a `.docx` in `docs/` and add an entry to the `DOCS` list near the top of the script in `index.html`. cards are read the way verbatim formats them and highlighting is what gets counted as a word.

you can also upload a file in the page itself. uploads are parsed in the browser and **are never sent anywhere**. zero user information will ever be stored.
